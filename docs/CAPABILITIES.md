# DeskPill 1.0

Native Windows desktop notch with five main pages: Music, Shelf, Focus, Water and Tasks. Includes Windows notification previews, clipboard history, OCR, calendar import and optional online tools. Personalization offers eight built-in skins plus one Custom palette with live preview.

See README.md for build instructions, privacy behavior and current limitations. Full local verification covers 252 checks across domain, parsing, Windows services, UI, notifications and motion. Hardware-dependent behavior requires an interactive Windows desktop.
