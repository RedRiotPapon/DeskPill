# DeskPill 2.1

Native Windows desktop notch with Music, Shelf, Focus, Water, Tasks and Agents. Hide unused pages without deleting their data. Classic, Glass, seven colored skins and a Custom palette support live preview.

Windows notification previews offer Open app, Copy and Recent actions. Esc dismisses a preview without activating DeskPill; unattended previews expire after a configurable two to fifteen seconds, with hover pausing the countdown. Recent retains up to 50 arrivals in memory. Per-app, focus and fullscreen preferences control peeks. Deferred previews coalesce to the newest eligible arrival. Opening a source launches its registered app, not a specific message.

Ctrl+Alt+V opens searchable text clipboard history. Select a result and press Enter to paste into the captured source window, or Ctrl+Enter to copy. Windows focus/input restrictions leave the text copied for manual paste. Clipboard persistence is off by default.

Also includes Windows media controls, OCR, focus timers, hydration tracking, tasks, calendar import and optional online tools. See the README for privacy behavior and limitations, and [performance measurements](PERFORMANCE.md) for measured coverage. Hardware-dependent checks require an interactive Windows desktop.

Optional English dictation is built into DeskPill: one-time verified speech-pack setup, hold Win+Space to speak and release to insert, Esc cancellation, an input-reactive waveform inside the notch, a 90-second cap, review after foreground changes, and guarded paste. The independent worker releases its offline model after each transcription. Dictation is off by default; enabling it takes over the Windows language-switch shortcut. English recognition was checked with generated audio without microphone or clipboard access; live microphone hardware and physical shortcut behavior still need user verification.

Settings → Motion provides opening/options delays, closing grace and spring pace with live preview, reset and cancellation. Glass appears directly after Classic, with opacity and highlight controls. It uses tinted translucency without a backdrop blur.

Game mode is available from the tray right-click menu and switches temporarily to compact, input-transparent Glass at 22% shell opacity while the foreground game matches a saved executable or fullscreen graphics heuristic. FPS is measured from PresentMon presentation intervals. Windows trace access is required; the current non-elevated test session verified the unavailable state, not live game FPS. With Game mode off, matching games tuck the notch into its tiny state without FPS capture. The saved theme and pointer behavior restore on game exit.

Music artwork/title opens its source app or a uniquely matched accessible browser tab. Chrome, Edge, Brave, Vivaldi, Opera, Firefox and Chromium source IDs are handled; live matching was checked read-only in Chrome. Volume uses a continuous, timed flyout with background audio writes and ordered mute actions. See [music behavior and limits](MEDIA.md).

Agents Home is a separate default-visible page, removable through Settings → Pages. Connection profiles select a tool and workspace; text and reviewed optional voice prompts run through Codex CLI, Claude Code or Gemini CLI in owned sessions, with follow-up, bounded responses, status and Stop. Review-only is default; Codex project writes are explicit opt-in. CLI sign-in and billing belong to the selected tool. App shortcut supports manual copy/open, without access to existing IDE, cloud or terminal conversations. Native `.exe` tools and verified official provider npm installations are supported through explicit asynchronous discovery. Unknown batch shims are rejected. Drafts, bounded transcripts, output and session UUIDs remain in memory. Hold/toggle voice and enabled Win+Space populate the open draft without sending. Codex supports explicit reviewed area/window/monitor images with per-draft ownership and temporary-file cleanup. Copy and guarded paste are user actions; there is no general computer-control loop. Quiet completion notices respect interruption controls. Closing DeskPill stops its owned process trees. Protocol, UI dispatch and process containment were tested using isolated fake CLIs; real provider calls, live microphone-to-agent dispatch and physical mixed-DPI capture were not performed. Geometry, synthetic image lifetime and UI routing were tested locally; renders were inspected at 100%, 125%, 150% and 200%. See [agent connection details](AGENTS.md).
